What is Context Window?
Answer :- maximum number of tokens can process in input and output combined

every llm model have specific Context window size that model can process.

why context window matter ?
suppose that you have 2 types of task 1.task like create 15-20 lines or code for specific task. 2. research on some topic or create coding files with multiple tasks.

for task 1 model don't need to process huge tokens. it simply create some sentence and some lines of code. and for task 2 model should process huge tokens.
model take time to genrate next token that not any ways to create all tokens at once. 

at this point context Window matter for us because for small task if we use high Context window llm that might they take more time than lower Context window llm. 
with latency cost matter because as i said company take cost based on model. think that for small task llm process huge tokens that create unnecessary bill to client.

based on task and input,output expexted tokens usage choose Context window.

when model have not sufficient knowledge, facts, news that time model hallucinate.examples :- current news or weather,personal data or not existed facts or datas.
