Laptop selection rules
----------------------
Product code controls the exact purchasable configuration. A customer who asks for 'an HP 14-inch laptop' has not specified enough information to uniquely identify VLT-HP-440G11-16 versus VLT-HP-640G11-32. Likewise, a request for 'Dell 16 GB' could match more than one record. The catalog should be queried using product code, exact model, or additional attributes before an exact specification is stated.

Warranty classes are also model-specific. Business-24 and Business-36 indicate different demonstration coverage periods. A support agent must retrieve the exact item record rather than assume that all business laptops carry the same warranty.

Laptop accessory notes
----------------------
Virelia Dock D450 is listed as a compatibility reference for selected business laptops. It is an accessory record, not a warranty extension. A laptop's docking support does not mean a dock is included in the demo price. Customers should distinguish included configuration from compatible add-ons.

Catalog ambiguity examples
--------------------------
'HP 16GB laptop' matches at least two catalog entries. 'Dell 14-inch 512GB' also matches more than one. 'Business-24 laptop' is not a unique identifier because several brands carry that class. These are useful retrieval tests because an answer that returns the first semantic match can be wrong even when every individual attribute sounds reasonable.
