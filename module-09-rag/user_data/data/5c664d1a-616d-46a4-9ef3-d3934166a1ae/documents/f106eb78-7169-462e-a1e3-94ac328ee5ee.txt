AC installation conditions
--------------------------
An AC purchase can contain both a product line and an installation line. The two should not be collapsed. Site assessment may examine electrical readiness, outdoor-unit placement, piping length and mounting conditions. The product's tonnage alone does not decide whether installation can proceed without review.

AC retrieval traps
------------------
A search for '5-star 1.5 ton' retrieves several products. The correct response depends on the brand, price, service class and product code requested. A search for '2 ton Blue Star' is much more precise and should retrieve VLT-AC-BS-20EI.
